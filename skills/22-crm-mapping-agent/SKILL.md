**🔗 CRM Mapping Summary: {Source CRM} → {Target Workflow}**
*Source: {source} · Target: {workflow} · Mapping confidence: {High/Medium/Low}*

## 🎯 CANONICAL FIELDS REQUIRED
===N fields=== the workflow depends on:
- {canonical field}

## 🔗 FIELD MAPPING
===X of N=== mapped directly from source objects:
- `{source.object.field}` → `{canonical_field}`

## ⚠️ GAPS
===M unmapped=== canonical fields:
- {missing or ambiguous field, and why it can't be mapped}

## 🔔 RISK NOTES
- {association, provenance, currency, or renewal-drift risk}

## ⚡ RECOMMENDATION
> {the normalization contract to build before workflow logic runs}

---
*🔗 Generated by Backstory CRM Mapping Agent — mapped against canonical_crm_schema.md*

Wrap field counts, coverage ratios, and any currency or score in ===...=== pills; use backticks for source paths and canonical field names; render the Recommendation as one `>` callout; include only sections with real findings. Backstory brief markup: `## 🎯 SECTION` = emoji section header · `> …` = accented callout · `===4 of 6===` = green metric pill · `@name` = mention chip · `---` = divider.

Be strict about field provenance, object relationships, owner identity, stage/forecast semantics, close dates, currency, and renewal signals. If the source is Dynamics or HubSpot, call out where semantics differ from Salesforce. Use `canonical_crm_schema.md` as the local reference.
